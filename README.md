# حسن ملکی‌فرد | انتخابات انجمن اولیا و مربیان

وب‌سایت اختصاصی معرفی و سوابق سرکار خانم **اعظم اسماعیلی** (نامزد انتخابات انجمن اولیا و مربیان مدرسه با نام همسرشان، آقای **حسن ملکی‌فرد**).

## پیام اصلی و شعار
- **شعار:** «در کنار هم، برای روزهای بهتر فرزندانمان 🌷»
- **محور فعالیت:** «با همدلی، مشارکت و همکاری خانواده‌ها و مدرسه، می‌توانیم محیطی بهتر، پویاتر و دوست‌داشتنی‌تر برای فرزندانمان بسازیم.»

## مشخصات نامزدی در انتخابات
- **نام در برگه رأی:** حسن ملکی‌فرد
- **معرفی و سوابق فعالیت:** اعظم اسماعیلی
- **سوابق:** ۴ سال حضور و همکاری در انجمن اولیا و مربیان مدرسه، منشی روابط انجمن، مشارکت فعال در برنامه‌های فرهنگی و هنری مدرسه

## اهداف و برنامه‌ها
۱. **شنیدن و پیگیری دغدغه‌های اولیا:** صدای اولیا بودن و پیگیری دلسوزانه پیشنهادها و انتقادها.
۲. **تقویت ارتباط میان خانواده‌ها و مدرسه:** افزایش تعامل سازنده میان خانواده‌ها و کادر مدرسه.
۳. **حمایت از فعالیت‌های فرهنگی، هنری و خلاقیت دانش‌آموزان:** کمک به نشاط، شکوفایی استعدادها و خاطره‌سازی برای بچه‌ها.
۴. **همکاری برای شناسایی و پیگیری مسائل مدرسه:** یافتن راه‌حل‌های عملی با همراهی سایر اعضا و مسئولان مدرسه.

## پالت رنگی (OKLCH)
- سبز لیمویی فسفری: `oklch(84.1% 0.238 128.85)`
- قرمز مایل به بنفش: `oklch(66.7% 0.295 322.15)`
- مشکی عمیق: `#171717`
- سفید: `#FFFFFF`

## پشته فناوری
- HTML5 معنایی (Semantic HTML5)
- CSS3 + Tailwind CSS v4 + Animate.css
- بدون جاوااسکریپت (Zero JavaScript)
- پشتیبانی کامل از چینش راست به چپ (RTL) و تایپوگرافی اصیل فارسی
